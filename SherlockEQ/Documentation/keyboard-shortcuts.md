# Keyboard Shortcuts

## Application

| Shortcut | Action |
| --- | --- |
| ⌘Q | Quit SherlockEQ |
| ⌘H | Hide SherlockEQ |
| ⌥⌘H | Hide others |

## Windows

| Shortcut | Action |
| --- | --- |
| ⌘0 | Show the main SherlockEQ window |
| ⌘W | Close the current window |
| ⌘M | Minimize |

Closing a window does not quit SherlockEQ — it keeps running in the menu bar.

## Audio

| Shortcut | Action |
| --- | --- |
| ⌘B | Toggle Reference Mode (bypass EQ) — main window |
| ⌥⇧⌘B | Global Reference Mode toggle (works from any app, when enabled in Settings) |

## Editing

| Shortcut | Action |
| --- | --- |
| ⌘Z / ⇧⌘Z | Undo / Redo profile edits |

## Expert Equalizer

| Shortcut | Action |
| --- | --- |
| Tab or L | Select next band (by frequency) |
| J | Select previous band |
| ↑ / ↓ | Nudge selected band gain |
| ⇧⌘↑ / ⇧⌘↓ | Fine gain adjustment |

Note: ⇧Tab is reserved by macOS for focus traversal and can't be used as a
"previous band" shortcut, which is why **J** serves that role.
